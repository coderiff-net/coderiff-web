# Blog cover image guidelines

Use a **16:9 landscape image** for blog post covers.

- Recommended source resolution: **1600 x 900 px**.
- Minimum source resolution: **900 x 506 px**. The blog cards request responsive variants up to 900 x 506 px.
- Keep important subjects away from the outer edges. Cards may crop a small amount to fill their frame.
- Use a full-bleed image without built-in blank borders or padding.
- The blog list and grid use `object-fit: cover` so images fill the card frame. Set `imageFit: contain` only for diagrams or artwork that must remain entirely visible; this may leave empty space around the image.

The card layout controls its own displayed dimensions. A blank band beneath a cover is a layout issue, not a reason to add extra canvas to the source image.
